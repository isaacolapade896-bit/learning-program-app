# Learning Program App

## Project Overview
The Learning Program App is a mobile application designed to help learners discover educational programs and allow administrators to manage program information.

## Project Objectives
- Make learning programs easy to discover.
- Allow learners to view program descriptions and requirements.
- Provide a simple and user-friendly mobile experience.
- Enable administrators to add, edit, and manage programs.

## Target Users
**1. Learners**
- Browse available learning programs.
- View program details.
- Manage their profiles.

**2. Administrators**
- View existing programs.
- Add new programs.
- Edit or remove program information.

## Planned Features
- User login and registration
- Home dashboard
- Program listing and search
- Program details
- User profile
- Admin dashboard
- Program management

## Planned Screens
1. Login Screen
2. Home Screen
3. Program Listing Screen
4. Program Details Screen
5. User Profile Screen
6. Admin Dashboard

## Navigation Flow
Login → Home → Program Listing → Program Details

Administrators will access the Admin Dashboard to manage learning programs.
